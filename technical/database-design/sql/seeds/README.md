
# SQL Seeds

Folder ini menyimpan query untuk mengisi data awal atau data pengembangan.

## Seed Categories

- Initial application data
- Organization reference data
- Development and testing data

## Guidelines

1. Pisahkan seed data dari migration schema.
2. Hindari memasukkan data sensitif atau data pribadi ke repository.
3. Pastikan seed dapat dijalankan sesuai kondisi database yang ditentukan.
4. Dokumentasikan tujuan setiap seed file.
5. Jangan menggunakan data produksi tanpa izin dan proses anonimisasi yang sesuai.

## Current Status

Seed files akan ditambahkan setelah data awal yang ditemukan dalam query historis dipisahkan dan ditinjau.
