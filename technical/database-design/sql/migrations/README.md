
# SQL Migrations

Folder ini menyimpan perubahan struktur dan konfigurasi database yang telah ditinjau.

## Migration Guidelines

Setiap migration harus:
- Memiliki nama file yang deskriptif.
- Memiliki urutan atau tanggal yang jelas.
- Menjelaskan tujuan perubahan.
- Mempertimbangkan kompatibilitas dengan struktur sebelumnya.
- Memperhatikan dampak terhadap data yang sudah ada.
- Memiliki pemeriksaan keamanan jika menyentuh RLS atau Storage.

## Current Status

Belum ada migration final yang ditetapkan dari kumpulan query historis.

Query historis harus melalui proses review dan pemisahan sebelum dipindahkan ke folder ini.
